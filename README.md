# ViGil — Agentic Malware Analysis System

> **Version:** 1.0.0 · **Stack:** PyTorch · FastAPI · CrewAI · Next.js · WebSocket

ViGil is an AI-powered malware analysis platform that combines a **Quad-Modal Deep Learning Model** with a **Multi-Agent Agentic System** powered by CrewAI. Upload any file and get a full MITRE ATT&CK-mapped threat intelligence report generated by 8 specialized LLM security analyst agents.

---

## How It Works

```
File Upload (Next.js)
        │
        ▼
FastAPI Backend  ──►  File Router  ──►  PE Deep Analyzer (15 modules, parallel)
        │                                       │
        │                               ML Model Predictor
        │                               JointMalwareModel (Quad-Modal)
        │                                       │
        │                               PE Analysis Crew (CrewAI)
        │                               ├── Phase 1: 5 Parallel Agents
        │                               │   ├── Structural Analyst
        │                               │   ├── Import Behavior Analyst
        │                               │   ├── Network Intelligence Analyst
        │                               │   ├── Evasion Specialist
        │                               │   └── String NLP Analyst
        │                               └── Phase 2: 3 Sequential Agents
        │                                   ├── Results Coordinator
        │                                   ├── ML Model Comparator
        │                                   └── Report Generator
        │
        ▼
 WebSocket  ──►  Real-time agent progress  ──►  Next.js Dashboard
```

## Setup & Run

### Step 1 — Install the UIR Library

The `uir` Python package must be installed before running the backend.

```bash
# From the project root (ViGil/)
pip install -e .
```

### Step 2 — Install Backend Dependencies

```bash
cd Agentic_System
pip install -r requirements.txt
```

### Step 3 — Configure Environment

```bash
# Copy the template
cp .env.example .env
```

Open `.env` and set your LLM provider credentials:

```env
# Choose your LLM provider: openai | gemini | ollama | nvidia_nim | openrouter | lmstudio
LLM_PROVIDER=openai

# Add your API key for the chosen provider
OPENAI_API_KEY=sk-your-key-here
OPENAI_MODEL=gpt-4o

# Model paths (relative to Agentic_System/)
MODEL_CHECKPOINT_PATH=../models/01/models/joint_model.pt
MODEL_CONFIG_PATH=../models/01/model_config.json
```

> See the full `.env.example` for all available options including Gemini, Ollama, NVIDIA NIM, OpenRouter, and LM Studio.

### Step 4 — Run the Backend

```bash
# From inside Agentic_System/
cd Agentic_System
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

The API will be available at **`http://localhost:8000`**.

Verify it's running:
```bash
curl http://localhost:8000
```

Expected response:
```json
{
  "status": "online",
  "title": "ViGil Agentic Malware Analysis System",
  "active_llm_provider": "openai",
  "ml_model_loaded": true,
  "device": "cuda"
}
```

### Step 5 — Run the Frontend

Open a **second terminal**:

```bash
cd Agentic_System/frontend
npm install
npm run dev
```

The dashboard will be available at **`http://localhost:3000`**.

## LLM Provider Configuration

ViGil supports 6 LLM providers. Set `LLM_PROVIDER` in `.env` and fill in the matching credentials:

| Provider | `LLM_PROVIDER` value | Required Keys |
|---|---|---|
| OpenAI | `openai` | `OPENAI_API_KEY`, `OPENAI_MODEL` |
| Google Gemini | `gemini` | `GEMINI_API_KEY`, `GEMINI_MODEL` |
| Ollama (local) | `ollama` | `OLLAMA_BASE_URL`, `OLLAMA_MODEL` |
| NVIDIA NIM | `nvidia_nim` | `NVIDIA_NIM_API_KEY`, `NVIDIA_NIM_BASE_URL`, `NVIDIA_NIM_MODEL` |
| OpenRouter | `openrouter` | `OPENROUTER_API_KEY`, `OPENROUTER_MODEL` |
| LM Studio (local) | `lmstudio` | `LMSTUDIO_BASE_URL`, `LMSTUDIO_MODEL` |

**Default models:**

```env
OPENAI_MODEL=gpt-4o
GEMINI_MODEL=gemini-2.5-flash
OLLAMA_MODEL=llama3
NVIDIA_NIM_MODEL=meta/llama-3.1-70b-instruct
OPENROUTER_MODEL=anthropic/claude-sonnet-4
LMSTUDIO_MODEL=local-model
```

You can also test your LLM connection via the Settings page in the dashboard or via API:

```bash
curl -X POST http://localhost:8000/api/settings/test-connection \
     -H "Content-Type: application/json" \
     -d '{"provider": "openai"}'
```

## Agentic System — 8 Agents

### Phase 1: Parallel Analysts

| Agent | Role |
|---|---|
| **Structural Analyst** | PE headers, sections, entropy, packer detection |
| **Import Behavior Analyst** | DLL imports, suspicious API patterns, call graphs |
| **Network Intelligence Analyst** | C2 indicators, URLs, IPs, suspicious domains |
| **Evasion Specialist** | Anti-debug tricks, VM detection, obfuscation techniques |
| **String NLP Analyst** | IOC extraction from strings, YARA match analysis |

### Phase 2: Sequential Synthesis

| Agent | Role |
|---|---|
| **Results Coordinator** | Synthesizes all 5 parallel agent outputs |
| **ML Model Comparator** | Compares agent verdict with ML model prediction |
| **Report Generator** | Writes final MITRE ATT&CK-mapped threat intelligence report |

**Output report format:**
```
# THREAT INTELLIGENCE & FORENSICS REPORT
# VERDICT: MALWARE
## CONFIDENCE: 94% | VIGIL THREAT MATRIX SCORE: 85/100
---
## 1. Executive Summary
## 2. File Metadata & Overview
## 3. Consensus & Logic Chain
## 4. In-Depth Technical Analysis
   ### A. Static Forensics & Indicators
   ### B. Evasion & Anti-Analysis Detection
   ### C. Network & C2 Indicators (IOCs)
## 5. MITRE ATT&CK Mapping
## 6. Defensive Recommendations & Mitigation
```

## ML Model — Quad-Modal JointMalwareModel

The `JointMalwareModel` combines 4 encoding streams for binary classification (`BENIGN` / `MALWARE`):

| Stream | Input | Encoder | Output |
|---|---|---|---|
| CPG Graph | Code Property Graph nodes/edges | OptimizedHGT (6-layer Transformer) | `[B, 768]` |
| Grayscale Image | PE bytes as 224×224 image | ConvNeXt-Tiny (pretrained) | `[B, 512]` |
| PE Bytes | First 1,024 raw bytes | AttentionByte 1D-CNN | `[B, 256]` |
| API Imports | Tokenized API names | CLSTransformerAPI (4-layer) | `[B, 256]` |

All 4 streams are fused into `[B, 1536]` and passed through a Deep Residual MLP to produce final logits.

**Monte Carlo Dropout** — 20 stochastic inference passes are run at prediction time to estimate epistemic uncertainty alongside confidence.

## Data & Memory

ViGil persists analysis data in a 4-tier memory system:

| Tier | Backend | Location | Purpose |
|---|---|---|---|
| Long-Term Memory | SQLite (async) | `Agentic_System/data/vigil_memory.db` | Full analysis history, IOC store |
| Knowledge Base | JSON file | `Agentic_System/data/knowledge_base.json` | MITRE TTPs, malware families, evasion patterns |
| Short-Term Memory | Python dict | In-memory | Per-session agent context |
| Entity Memory | Built on LTM | SQLite | Cross-analysis IOC correlation |

Previously analyzed files are **deduplicated by SHA256** — re-uploading the same file returns the cached result instantly.

## Troubleshooting

**`ModuleNotFoundError: No module named 'uir'`**
```bash
# Install the UIR library from the project root
pip install -e .
```

**`ml_model_loaded: false` in health check**
- Verify `MODEL_CHECKPOINT_PATH` in `.env` points to an existing `joint_model.pt` file.
- Check backend logs — the model loads in the background at startup.

**`CORS error` in browser**
- Confirm `FRONTEND_URL=http://localhost:3000` is set in `.env`.

**LLM connection fails**
- Use the Settings page → "Test Connection" to verify your API key and model name.
- For local providers (Ollama/LM Studio), ensure the local server is running before starting ViGil.

**Port already in use**
```bash
# Change the backend port
BACKEND_PORT=8001 uvicorn backend.main:app --port 8001

# Change the frontend port
npm run dev -- --port 3001
```
